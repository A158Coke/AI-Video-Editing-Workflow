# Brief and storyboard

Write the brief before choosing shots. Capture:

- audience, platform, aspect ratio, target duration, and delivery format;
- the central message or narrative arc;
- required, optional, and forbidden content;
- voice, live sound, effects, BGM, and silence policy;
- source permissions, brand constraints, privacy concerns, and acceptance tests.

The storyboard should be executable. Each row should identify the source and time range, target duration, visual purpose, text, audio, transition, and review status. Use stable shot IDs and keep the file in UTF-8.

For a general promo, a useful starting arc is:

```text
context/problem → evidence/process → turning point → result → next action
```

This is a starting pattern, not a requirement. Documentary, match, product, and chart-focused edits may use different structures; record the chosen structure in the project brief.
