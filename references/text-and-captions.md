# Text, captions, and multilingual graphics

- Keep copy in UTF-8 text or structured data; keep rendering code separate from wording.
- Choose fonts that cover the actual character set and define a fallback.
- Test line breaks, punctuation, glyph coverage, contrast, safe areas, and subtitle timing with real copy.
- Do not add captions, corner labels, logos, or watermarks unless the brief requires them.
- For RTL text, emoji, vertical writing, or mixed scripts, use a renderer that supports the required shaping and test on the target player.
- If text is derived from a source video, distinguish source subtitles from newly added overlays in the manifest.
