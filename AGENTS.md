# Agent instructions

This repository is vendor-neutral. Read [`WORKFLOW.md`](WORKFLOW.md) before changing workflow or reference files.

Keep the canonical rules in `WORKFLOW.md`; do not create agent-specific forks of the workflow. Project-specific facts belong in the consuming video project, not this repository.

Use the host agent's available file, shell, media-inspection, and validation tools. If a capability is unavailable, report the missing gate instead of claiming the output was verified.
